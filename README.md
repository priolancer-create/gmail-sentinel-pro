## 📌 পরিচিতি

**Gmail Sentinel Pro** একটি হালকা ও শক্তিশালী পাইথন কমান্ড-লাইন টুল, যা Gmail-এর SMTP সার্ভার ব্যবহার করে ইমেইল পাঠায়। কোনো বাইরের লাইব্রেরি (`pip install`) লাগে না, শুধু পাইথন থাকলেই চলে।

> 💡 **কেন এটি?** আপনার পাসওয়ার্ড কোথাও সেভ হয় না, সংযোগ সবসময় TLS দিয়ে এনক্রিপ্টেড থাকে, আর কমান্ড দিয়ে অটোমেশনও করা যায়।

## 🚀 দ্রুত শুরু

### ১) প্রয়োজনীয় জিনিস

- 🐍 Python **3.8** বা তার উপরের সংস্করণ
- 📧 একটি Gmail অ্যাকাউন্ট
- 🔐 Google **2-Step Verification** চালু থাকতে হবে
- 🗝 একটি **App Password**

### ২) Google App Password তৈরি করুন

```
Google Account  →  Security  →  2-Step Verification (চালু করুন)
                →  App passwords  →  একটি নাম দিন  →  Create
```

১৬ অক্ষরের পাসওয়ার্ডটি কপি করে রাখুন। স্পেস থাকলেও সমস্যা নেই, টুল নিজেই সরিয়ে নেয়।

> ⚠️ আপনার সাধারণ Gmail পাসওয়ার্ড এখানে **কাজ করবে না**।

### ৩) চালু করুন

```bash

```

## 📖 ব্যবহারের নিয়ম

### 🖱 মোড ১: ইন্টারঅ্যাকটিভ মেনু

```bash
python gmail_sentinel_pro.py

```

```
  ────────────────────────────────────────

  1  Send email
  2  Test connection

```

### ⌨️ মোড ২: কমান্ড-লাইন

**কানেকশন টেস্ট:**

```bash
python gmail_sentinel_pro.py test
```

**সাধারণ ইমেইল:**

```bash
python gmail_sentinel_pro.py send \
  -t friend@example.com \
  -s "হ্যালো" \
  -b "কেমন আছেন?"
```

**অ্যাটাচমেন্ট ও Cc সহ:**

```bash
python gmail_sentinel_pro.py send \
  -t boss@example.com \
  --cc team@example.com \
  -s "মাসিক রিপোর্ট" \
  --body-file message.txt \
  -a report.pdf -a chart.png \
  --yes
```

**HTML ইমেইল:**

```bash
python gmail_sentinel_pro.py send -t a@example.com -s "Newsletter" \
  --html --body-file newsletter.html
```

### 🧰 কমান্ড অপশন (`send`)

| অপশন | অর্থ | আবশ্যক |
|---|---|:---:|
| `-t`, `--to` | প্রাপক (কমা দিয়ে একাধিক) | ✅ |
| `-s`, `--subject` | বিষয় | ✅ |
| `-b`, `--body` | মেইলের লেখা | ⚪ |
| `--body-file` | ফাইল থেকে লেখা পড়ুন (`-` দিলে stdin) | ⚪ |
| `--cc` | Cc প্রাপক | ⚪ |
| `--bcc` | Bcc প্রাপক (গোপন) | ⚪ |
| `-a`, `--attach` | ফাইল সংযুক্তি (একাধিকবার দেওয়া যায়) | ⚪ |
| `--html` | বডি HTML হিসেবে পাঠান | ⚪ |
| `--from` | আপনার Gmail ঠিকানা | ⚪ |
| `-y`, `--yes` | কনফার্মেশন প্রম্পট বাদ দিন | ⚪ |
| `-v`, `--verbose` | ডিবাগ লগ দেখান | ⚪ |

> `-b` বা `--body-file`-এর একটি অবশ্যই দিতে হবে।

### 🌱 Environment Variable (ঐচ্ছিক)

বারবার টাইপ করা এড়াতে:

**Linux / macOS**
```bash
export GMAIL_ADDRESS="you@gmail.com"
export GMAIL_APP_PASSWORD="abcd efgh ijkl mnop"
```

**Windows (PowerShell)**
```powershell
$env:GMAIL_ADDRESS = "you@gmail.com"
$env:GMAIL_APP_PASSWORD = "abcdefghijklmnop"
```

> 🔔 এই মান শুধু বর্তমান টার্মিনাল সেশনে থাকে। টুল নিজে কখনো পাসওয়ার্ড ফাইলে লেখে না।

- দৈনিক পাঠানোর সীমা আছে (সাধারণ অ্যাকাউন্টে প্রায় **৫০০ প্রাপক/দিন**, সীমা পরিবর্তন হতে পারে)

## 🛠 সমস্যা সমাধান

| সমস্যা | সম্ভাব্য কারণ | সমাধান |
|---|---|---|
| `Authentication failed` | সাধারণ পাসওয়ার্ড দিয়েছেন বা App Password ভুল | নতুন App Password বানিয়ে আবার দিন |
| App Password অপশন নেই | 2-Step Verification বন্ধ | আগে 2-Step Verification চালু করুন |
| `Connection timed out` | ইন্টারনেট বা ফায়ারওয়াল সমস্যা | নেটওয়ার্ক দেখুন, পোর্ট `587` খোলা আছে কিনা যাচাই করুন |
| `Recipient rejected` | প্রাপকের ঠিকানা ভুল | ঠিকানা পরীক্ষা করুন |
| `Attachments exceed 25 MB` | ফাইল বড় | ফাইল ছোট করুন বা লিংক শেয়ার করুন |
| রঙ দেখা যাচ্ছে না | টার্মিনাল ANSI সাপোর্ট করে না | স্বাভাবিক, টুল নিজেই রঙ বন্ধ করে নেয় |
| বিস্তারিত ত্রুটি দেখতে চাই | | `-v` অপশন দিয়ে চালান |
